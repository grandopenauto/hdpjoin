# HDPJoin.com — Manifested Miracles

Discovery and learning portal for Highest Degree Priorities. Built as a public GitHub Pages website on `main` with custom domain `hdpjoin.com`. This is the educational first stop; the intentional buyer journeys lead to [Highest Degree Priorities](https://www.highestdegreepriorities.com/).

## What this site is for

- Introduce the HDP mission and Business Operating Systems in accessible language.
- Publish genuinely useful original educational articles and comparison guides.
- Help visitors choose between a single useful task and a complete business operating system.
- Provide a curated video/demo gallery when source links have been approved.
- Offer RSS updates and a clearly labeled email newsletter request until a consent-capable mailing platform is connected.
- Send measurable, relevant referral links to HDP's Business Launchpad and Tasks Marketplace.

## Launch notes

Site sources are intentionally static: HTML, CSS, JavaScript, RSS/XML. GitHub Pages should be configured to deploy from `main` / `(root)` once the owner enables it under Settings → Pages. `CNAME` must be set to `hdpjoin.com` and DNS must point at GitHub Pages. Enable HTTPS when GitHub provisions the certificate.

Do not confuse requests for newsletter updates with an active subscription, and do not claim purchase or activation occurs on this site. See `CONTENT_GUIDE.md` for publishing and consent guidelines.
